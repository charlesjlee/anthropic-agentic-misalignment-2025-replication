# Published study data

`anthropic_datacenter_10_retained_models.csv` contains the six Table A3 values for each of the ten models retained in the original headline figure, with exclusion flags and vendor display order. These are published study data, not our own run results.

Source: [Anthropic's technical appendix, Table A3, pp. 29-30](https://assets.anthropic.com/m/6d46dac66e1a132a/original/Agentic_Misalignment_Appendix.pdf#page=29).

The root README's combined figure is generated by `scripts/build-readme-results.py`, using this CSV, the additional published GPT-4o/Maverick values in `experiments/historical/table-a3.json`, and the saved local results snapshot.
